## 🌟 Overview

A modern, neo-brutalist editorial portfolio built with **React & Vite** for **Piyush Mittal** (Video & Reel Editor based in Gwalior).

### 🚀 Key Features
- **Neo-Brutalist & Streetwear Zine Aesthetic**: Graph-paper blueprint grid background, torn paper edge dividers, and kinetic typography.
- **Hardware-Accelerated 60 FPS Video Theater**: Auto-playing muted previews with zero layout thrashing or stutter.
- **Adaptive Cinema Modal**: Automatically detects aspect ratios — displays vertical 9:16 reels in full-height portrait mode, and 16:9 videos in wide landscape format.
- **Pure Minimalist Player Controls**: Includes one-click direct **Video Download**, **Copy Share Link**, and custom video scrubber.
- **Cloudinary Direct Upload (No Backend Required)**: Upload videos from local machine directly to Cloudinary cloud storage using unsigned presets.
- **Owner Video Management**: Discrete owner controls to upload and delete reels in 1 click (with `Ctrl + U` shortcut).
- **Formspree AJAX Integration**: Contact form routed directly to `mittalp238@gmail.com` with WhatsApp and direct call buttons (`+91 8120945337`).

## 📦 Getting Started

### 1. Clone & Install
```bash
git clone https://github.com/piyushmittal16/Video-Editing-Portfolio.git
cd Video-Editing-Portfolio
npm install
```

### 2. Run Locally
```bash
npm run dev
```
Open [http://localhost:5173/](http://localhost:5173/) in your browser.

### 3. Build for Production
```bash
npm run build
```
